# D04 — Visualizer Tools: Pixel Layouts & Animation Choreography

Shared chrome first, then per-tool specs. These screens are the product's soul — every timing here is deliberate.

---

## 0. Shared tool chrome

**Page frame:** full-width workspace under nav; tool header 56px: tool name 20/650 + stage chip + example dropdown (180px) + Share (splits into copied-link toast: "Link copied — this exact state") + ⛶ focus mode. Content region = docked panels with 6px splitters (hover: splitter tints cobalt, cursor col-resize; drag: 1px cobalt guide line).

**TransportBar (the signature control, 56px, bottom-fixed within tool):**
```
|⏮|←8→|◀ step|←8→| ▶ Play (44px circle, leaf) |←8→|step ▶|←8→|⏭|←24→|═══ timeline scrubber ═══|←24→|0.25×…4× speed|←16→|🐞 Debug|
```
- Timeline: 6px track paper-2; progress fill = stage accent; **event ticks**: 2px marks on the track for every significant event (token emitted, reduce, state split) — hovering a tick previews its frame in a 160px thumbnail popover; clicking jumps. Dragging scrubs all panels in perfect sync at 60fps (precomputed frames).
- Play button: ▶ morphs to ⏸ via 150ms path interpolation. Speed: text button cycling with a 100ms number-roll.
- Keyboard: space play/pause, ←→ step, shift+←→ jump-to-event, [ ] speed.

**StepLog drawer:** 32px collapsed bar above transport ("Reduce by E → E + T; goto 9" — latest line, typing effect 20ms/char); expands to 200px scrollable transcript; every line click-jumps the timeline. This is also the `aria-live` stream.

**Sync-highlight grammar (platform-wide law):** hover/tap any artifact → **all** of its provenance relatives highlight within 80ms: accent-200 fill on spans, 1.5px accent outline on nodes, connector lines draw between panels when panels are adjacent (SVG overlay, 150ms ink-draw, fade 200ms on leave).

## 1. Lex Machine (`/tools/lex`)

**Layout (1440):** Spec panel 360px | Machine (flex, ~640px) | Output 400px; transport bottom.

**Spec panel:** three bands with 36px band headers (caption + count chip + collapse chevron). Rule rows 56px: pattern (regex-syntax-highlit mono 14) · priority badge (20px circle, ink) · hit counter (tabular, ticks with a 4px pop per hit) · 32×20px DFA thumbnail (live mini-render) · action expands below (mono 13, C-highlit, max 120px). Active rule during simulation: row gets marigold-100 wash + 3px marigold stripe (80ms). Macro chips in patterns: cobalt-100 pills; hover draws an ink line to the definition row (bezier over the panel, 150ms).

**Machine center:**
- **Input tape (top, 96px):** character cells 36×44px, mono 18, 2px gaps, paper cells with hairlines; the tape scrolls horizontally keeping the cursor in the center third. Cursor: 3px marigold caret + soft 8px glow, slides cell-to-cell in **120ms ease-in-out per char at 1×** (scales with speed). Consumed cells tint marigold-100 at 60%. `yytext` bracket: 2px ink underline elastic-stretches beneath the current lexeme. **Last-accepting bookmark:** 14px 📍-style ink pin drops (150ms, small bounce) above the cell; on dead-state, cursor **rewinds** — 80ms/cell backward with a 12px motion-blur streak + a soft "shhk" (all sounds optional, off by default) and cells un-tint as it passes; the pin flashes leaf and the accept fires.
- **DFA canvas (center, ~400px):** states 44px circles (2px ink stroke, accepting = double ring 4px gap); state labels mono 13 inside; edges 2px with 20px-curvature auto-routing, labels in 11px pills on the edge midpoint. Active state: accent radial pulse (scale 1→1.35 opacity .5→0, 300ms) each transition; traversed edge flashes: dash-offset sweep 150ms in marigold. Accepting states color-tagged by owning rule (4px outer arc in rule color). Layout auto (dagre LR), nodes draggable (snap 8px grid), positions persist in share-state.
- **Token emission:** on accept — the lexeme's cells clone, converge into a chip (200ms), chip springs to 1.0 and flies a 350ms bezier to the Output token stream; simultaneously the winning rule row flashes and its action code expands 200ms showing live `yytext="count"` `yyleng=5` value pills inline, then re-collapses. Priority tie: both rules flash, loser dims to 40% with "same length — rule ① wins" 12px caption, winner keeps a ① ribbon 2s.
- **Rejection:** cell shakes ±3px ×2, tints coral-100; a "cascade" runs down the rule list — each row briefly lifts 2px and drops (40ms apart) showing "no match" — then the default ECHO chip (gray, dashed border) emits.

**Output panel tabs (36px pill tabs):** Tokens (chips 28px in wrap rail + table below: 5 cols, 40px rows, hover = three-way sync) · Generated C (mono 13, folded sections with region labels "— YOUR ACTION CODE —" in marigold; gutter map dots link to DFA states, hover cross-highlights) · Performance (after run: 4 KPI tiles 96px + per-rule hit BarChart, bars grow 400ms staggered; backtrack warnings coral with "anchor rule 3" advice chips) · Console.

**Debug mode:** transport swaps to instruction-stepping; inspector strip 64px above transport: 6 value cells (state#, yytext, yyleng, line, start-cond, last-accept) — values flip with a 120ms roll on change. Rule breakpoints: 12px coral dot toggles on row hover-gutter; hit = timeline pauses + row pulses.

## 2. Regex Lab (`/tools/regex*`)

**Layout:** top pattern bar (full-width 72px: pattern input mono 20 + flavor select + ▶) → four synced quadrants (2×2 grid, splitters): Test input (TL) · Explainer (TR) · NFA (BL) · DFA (BR). Any quadrant maximizes on ⛶ (300ms layout spring).

- **Pattern input:** as-you-type syntax coloring (classes leaf, quantifiers marigold, groups cobalt brackets with matching-pair glow on caret adjacency, anchors orchid). Invalid pattern: coral wavy underline exactly on the broken span + hint chip below.
- **Test input & matching:** matches get alternating leaf-100/leaf-200 stripes (rounded 4px); group captures nest with 2px inset rings per depth (max 4 depths). ▶ run: cursor pulse per char 100ms@1×; **backtrack**: cursor steps back with fading coral trail segments (each 300ms fade) + backtrack counter chip ticking top-right (turns coral >100, explodes into the catastrophic-backtracking teach-card >10k with a "why did this happen?" link). Engine toggle (Backtracking/Thompson): in Thompson mode 2–6 ghost cursors (40% opacity carets) advance simultaneously — dying cursors pop like soap bubbles (120ms).
- **Explainer:** indented tree rows 36px, plain-English 14px, each row's regex-span chip in mono; hover row = tri-highlight (pattern span + all match spans + NFA fragment outline). AI "explain deeper" ghost button per row.
- **NFA quadrant:** Thompson fragments assemble as you scrub a **construction timeline** (secondary 4px scrubber at quadrant top): concat = boxes magnet-snap (150ms) with a 1px flash; alternation = diamond rails draw outward; star = ε loop-back draws as dashed ink 250ms. ε-edges always dashed 4-2. Simulation: **active-set** glow — multiple states hold a soft leaf halo simultaneously (the pedagogical money-shot; halo = 6px blur accent at 45%).
- **DFA quadrant:** subset construction: each new DFA bubble (52px, contains up to 6 mini NFA dots 8px) materializes with a **lasso animation** — a dashed ink loop draws around the source NFA states in the NFA quadrant (400ms), then contracts and flies (300ms) into the DFA quadrant forming the bubble. Transition table fills row-by-row beneath (rows 32px, cell fills with 80ms tint). Minimization: partitions as two large tinted regions; each split = a cell-division animation (region pinches 300ms, separates with 8px gap); final morph old→minimized: shared states glide to new positions (500ms), removed states shrink-fade.
- **Builder mode** (tab): block palette left 200px (blocks 44px, grab cursor); canvas rail center — blocks snap with a 4px magnet click (haptic on mobile); textual regex writes itself under the rail (per-char typed as blocks land). Bidirectional: editing text re-lays blocks with FLIP transitions (300ms).
- **Generator (AI) mode:** two example lists (should/shouldn't match, chips with ✓/✗ 20px); Generate → proposed pattern appears typed, then the **verification wall**: each example chip flips (200ms, 60ms stagger) to leaf/coral; failures trigger visible auto-retry ("attempt 2 of 3" caption). Optimizer: before/after cards + DFA state-count "34 → 12" with the number rolling down and a small applause from Lexi (one-frame wink).

## 3. Parser Theater (`/tools/parser`, `/tools/grammar`, `/tools/ast`, `/tools/bison`)

**Grammar Builder:** production rows 48px: LHS nonterminal (cobalt 15/600) → `→` → RHS symbol chips (terminals = token chips, nonterminals = cobalt outline pills) with `|` separators; row hover: grip + duplicate/delete icons fade in. **Autopsy panel** (right 380px): runs on 600ms debounce — result cards stagger in: Left recursion (offending cycle drawn as a mini graph with the cycle edge pulsing coral) · Ambiguity (the two parse trees render side-by-side 280px, differing subtrees haloed coral — the definition, visualized) · **Compatibility report**: 4 badges (LL(1)/SLR/LALR/CLR) as accepting-state rings — pass = leaf double-ring draws; fail = ring breaks with a 2px gap + crack line, tooltip names the exact conflict, click deep-links Conflict Cinema. Transform assistants: "Fix left recursion" → the production row splits in two with a cell-division animation; old symbols visibly migrate to their new homes (400ms FLIP), a before/after diff card remains.

**FIRST/FOLLOW:** center = productions list; right = set bags (per nonterminal, 64px rounded bins). Play: algorithm walks productions — current production spotlights (rest dim to 60%); derived terminal chips **toss** into bags (350ms arc + tiny bag squash on landing 80ms); each toss logs its reason line. FOLLOW: propagation arrows draw between productions (ink bezier, 200ms) before chips move. Practice mode: drag chips from a tray into bags — wrong chip bounces out (spring, 250ms) + the violated rule card slides in; bag completion = double-ring stamp.

**LL(1) view:** table (left, cells 64×36px) · stack (center, plates 120×32px stacked) · tape (right). Step: consulted cell flashes cobalt-200 (200ms) → top plate lifts 8px and fades → RHS plates drop in reverse order (60ms stagger, each lands with 2px settle) → terminal match: stack plate and tape cell both tint leaf, plate flies to the cell and both dissolve (300ms). Conflict cells: coral fill + diagonal hatch pattern (pattern = redundancy for color-blind users).

**LR automaton construction:** state cards 200×auto (kernel items bold, closure items regular, 13px mono); new state: card scales in 0.9→1; closure items fade in sequentially (80ms) each with its reason production flashing in a side ribbon; GOTO edges ink-draw 250ms with symbol pill. Family morph (SLR↔LALR↔CLR segmented control): **the merge animation** — same-core CLR states glide toward each other (600ms), overlap, and fuse with a soft flash; their lookahead sets visibly union (chips from both slide into one row, duplicates merging with a blink); state-count ticker rolls down. Reverse (LALR→CLR) plays the split.

**ACTION/GOTO table:** sticky header/first-col; cells 56×32px: shift `s5` cobalt, reduce `r3` orchid, accept leaf with mini double-ring, conflicts coral+hatch showing both entries stacked 10px. Hover cell ↔ automaton state + producing items highlight. **Conflict Cinema:** click a conflict cell → modal 1040×640px: split stage, shared input tape on top; left runs SHIFT future, right runs REDUCE future — synchronized until divergence (divergence moment marked by a 2px vertical coral flash), then each side's tree grows independently; a failing side ends with its tree graying + collapsing (400ms); verdict banner explains. Precedence fix applied → the cell in the background table gets a wax-seal stamp animation ("resolved: shift — `*` > `+`", 300ms stamp + 1.05 settle).

**Shift-reduce execution (the hero animation):** stack (plates: symbol plate + thin state plate 16px on top) · tape · **growing forest** panel. Shift: tape chip slides (300ms bezier) onto stack, state plate stamps (80ms drop + shadow pulse). Reduce: handle plates glow the production's color (150ms) → lift **together** 12px → fold into one nonterminal plate (280ms, plates rotate slightly inward like closing a book) — simultaneously in the forest, those subtrees' roots draw branches (ink, 120ms each) up to the new parent node which pops in. GOTO consult flashes in the docked mini-table. Accept: root-to-leaves shimmer wave (leaf-200, 500ms) + the whole tree does a 1° settle.

**AST view:** parse-tree/AST morph toggle: intermediate chain nodes (E→T→F) collapse — each chain contracts along its edge (250ms, 40ms stagger bottom-up), survivors glide into compacted layout (FLIP 400ms). Node expand: 200ms accordion revealing attribute rows (type/value chips). Canvas: pan (drag), zoom (wheel 0.4–2×), minimap 160×100px bottom-right, export button renders SVG/PNG at 2×.

**Error recovery:** panic mode — discarded tape chips detach and **fall** (350ms gravity arc, rotate ~30°, fade) until a sync-token chip glows leaf ("synchronized on `;`"); error productions — a special gray `error` plate visibly absorbs adjacent plates (they slide into it, 200ms each). Recovery report card after: tokens discarded, subtrees salvaged.

**Bison Builder:** left = `.y` editor (Monaco); right tabs: Conflicts (each row deep-links Cinema) · Tables (stats tiles + full table) · Generated `y.tab.c` (user actions highlighted marigold) · **Run dock**: when a Lex Machine spec is attached, the two panels dock with a hatch between them — every `yylex()` call animates a chip passing through the hatch (120ms) into the parser's tape. Docking animation: panels slide together, hatch draws, a satisfying clunk settle (2px).

## 4. Pipeline Explorer (`/tools/pipeline`)

**Conveyor:** 9 stage cards 120×88px (as home S2) on a 2px rail with animated dash-flow (dashes drift 1px/s toward Executable — perpetual gentle motion). Global play: the artifact packet traverses; entering a stage triggers that stage's compact animation (2–6s each per doc 09). Click stage → **inspector expansion**: card grows to fill 100%×520px (450ms spring), conveyor shrinks to a 40px breadcrumb strip on top (stages as 24px dots, current filled); inspector contains that stage's full visualizer (embedding the exact components above). Esc/breadcrumb click returns (350ms).

- **Semantic stage:** checker cursor = a 16px lens glyph walking the AST depth-first (150ms/node); type stamps: 20px pills rotate in −8°→0° (120ms) onto nodes; symbol table right rail fills row-by-row (each row slides in 150ms) with scope indent guides; scope enter/exit: table section wraps in a bracket that draws/retracts. Type error: subtree floods coral bottom-up (80ms/node) + explanation card.
- **IR stage:** TAC lines fly out of their AST subtrees (each line: subtree glows → line materializes typed 15ms/char in the IR panel, 350ms flight ghost). Temporaries: `t1` birth = small counter odometer tick. CFG view toggle: lines regroup into basic-block cards (FLIP, 500ms) + edges ink-draw.
- **Optimize stage:** pass list left (toggleable, drag-reorder with FLIP); center split diff. Constant fold: operand tiles slide together, squash (1.0→0.85→1.0), fuse into result tile with 6-particle paper puff. DCE: dead lines desaturate → crumble (clip-path crumble + 8px fall + fade, 400ms, 60ms stagger). CSE: lasso draws around both duplicate expressions (300ms), second one's tile swaps to `t3` with a flip. LICM: the invariant line physically **lifts out** of the loop-body card (350ms arc) and lands above it with a settle.
- **Codegen stage:** register strip: 8 slots 72×40px (labeled x1…) across the top; values = colored tokens moving in/out (250ms arcs); spill: token gets pushed off the strip's right edge onto a "stack" card below (gravity arc + stack grows). TAC→asm lines translate with a per-line typewriter + provenance thread (1px accent line momentarily connecting source TAC line, 400ms fade).
- **Compare mode:** two conveyors stacked with a shared scrubber; any stage diff badge (±n lines) — clicking shows a unified diff overlay; the changed-line ripple: edit in source → each downstream stage's affected artifacts flash amber sequentially left→right (100ms apart) — the "ripple of one line" is the mode's signature moment.
- **Tour mode:** letterboxed (top/bottom 48px ink bands), captions typed bottom-center, camera (panel scroll) glides between stages; 90s total; skippable; ends with "now you drive" + controls glowing once.
