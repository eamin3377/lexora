## Non-negotiables carried through every document

1. **Light theme only** — Paper & Ink; the terminal is the sole dark *element*.
2. **Motion is pedagogy** — cause before effect, visible provenance, everything scrubbable.
3. **3D is papercraft, not sci-fi** — one hero machine, locked palette, explicit ban list.
4. **No AI-generic patterns** — no purple/black gradients, no hexagon-brain logos, no bouncing-dot clichés (ours wobble like Stax).
5. **Every value is specified** — if a duration, size, or color isn't in these docs, it doesn't ship.
